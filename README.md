# jarandana: tu casa, sin taladrar

Marca de hogar (Shopify, España → UE) con **7 productos útiles para baño y cocina que se instalan sin agujeros**, aguantan la humedad y se pueden llevar al mudarse: balda de ducha, rasqueta de mampara, ganchos, kit de fregadero, esquinera doble, bayetas y recambio de adhesivos.

**Por qué este foco dentro de "hogar":**
- El 20,2 % de los hogares españoles vive de alquiler (54,7 % entre los menores de 30) y **no puede taladrar sin permiso** (art. 23 LAU).
- Buena parte del país tiene **agua muy dura** (Valencia, Alicante, Murcia, Barcelona).
- **#CleanTok** mueve la compra de hogar en TikTok España.
- El hogar genérico se lo reparten Temu, Action e IKEA a precio mínimo. El hueco está entre lo barato que se despega y lo fiable con estética de ferretería (Wenko, tesa).
