# FAROLA · Walk Club — propuesta de negocio (Shopify, España → UE)

Tienda de nicho de **accesorios de paseo urbano para perros**: un *sistema* de 7 productos que se enganchan entre sí (botella limpia-pis, dispensador, bolsas, bolsa de premios, bandolera, portabolsa y botella-bebedero).

**Por qué este nicho, en una frase:** muchas ciudades españolas (y también italianas) obligan a limpiar el pis del perro y multan por no hacerlo, pero lo que se vende son botellas genéricas de 5 € o regaladas por el ayuntamiento. Nadie vende todavía en España un sistema de paseo con marca y diseño. Además, las bolsas son un consumible y generan recompra.
